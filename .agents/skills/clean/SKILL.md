# 소스 코드만 남기기

지우기는 **반드시 스크립트로만** 한다(`scripts/clean.sh`). `rm -rf` · `docker rm` 을 손으로 부르지 않는다 — 무엇이 이 프로젝트의 것인지, 무엇을 남기는지를 스크립트가 갖고 있다.

## 흐름 넷

1. **보인다** — `scripts/clean.sh` (지우지 않고 목록과 크기만)
2. **묻는다** — 목록을 사용자에게 그대로 보이고 지워도 되는지 묻는다. **대답 없이 지우지 않는다**
3. **지운다** — 허락을 받으면 `scripts/clean.sh --yes`
4. **보고한다** — 무엇을 지웠는지, 다시 갖추는 법(`bootstrap` 스킬, 모델 약 1GB · 모델 서버 이미지를 다시 받는다)

## 지우는 것

| 단계 | 지우는 것 |
|---|---|
| 1 | `scripts/serve.sh` 로 띄운 서버 · 화면 (내린다) |
| 2 | 저장소 안에서 git 이 무시하는 것 — `node_modules` · `.venv` · 캐시 · `dist` · 시드 DB · 변이 테스트 사본 · 평가 원자료 · 끝단 테스트 결과 · `.run` |
| 3 | 이 프로젝트의 도커 자원 — 컨테이너 `sales-agent-ollama` · `sales-eval-ollama`, 볼륨 `sales-agent_ollama`(받아 둔 모델), 이미지 `sales-agent:local`, 이미지 `ollama/ollama:latest`(다른 컨테이너가 쓰지 않을 때만) |
| 4 | `--global` 일 때만 — 테스트 브라우저(Playwright), 이 컴퓨터에 설치한 Ollama 의 모델. 다른 프로젝트도 쓸 수 있어 따로 묻는다 |

## 지우지 않는 것

* git 이 추적하는 파일 — 소스 코드 · 문서 · 설정
* 추적하지 않지만 무시되지도 않는 파일 — 작업 중인 새 파일
* 설정 파일 `.env` — 사용자가 넣은 값이 있다
* 다른 프로젝트의 도커 자원 — 이름으로 이 프로젝트의 것만 고른다
* git 설정(훅 켜기 등), uv · npm 의 전역 캐시

## 하지 않는 것

* **허락 없이 `--yes` 를 붙이지 않는다.** 모델 · 이미지를 다시 받는 데 수 GB 와 시간이 든다.
* **`--global` 은 사용자가 따로 원할 때만** 쓴다.
* **목록에 없는 것을 손으로 더 지우지 않는다** — 더 지울 것이 있으면 스크립트를 고치자고 제안한다.
