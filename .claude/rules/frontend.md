# 화면 규칙

## 구조

| 자리 | 무엇을 |
|---|---|
| `api/` | 서버 호출과 SSE 해석. 화면을 모른다 |
| `components/` | 화면 조각. 서버를 직접 부르지 않는다 |
| `App.tsx` | 상태와 조립 |

* 서버 응답 타입은 `api/types.ts` 한 곳에 둔다. 서버의 이벤트 이름(`docs/design/query.md` 2.4)과 같게 쓴다.
* SSE 해석은 순수 함수로 두고 테스트한다. `fetch` 를 부르는 코드와 섞지 않는다.

## 표시

* **결과 숫자를 가공하지 않는다.** 천 단위 구분만 넣고 반올림 · 단위 변환을 하지 않는다 (NFR-002).
* 실패 사유는 사용자가 다음에 무엇을 할지 알 수 있게 보여 준다.
* 스타일은 CSS Modules. UI 라이브러리를 들이지 않는다.
